# Product Thinking — Summary & Quiz

A single-page study aid summarising the [Institute of Digital Government's Product Thinking pathway](https://www.idg.gov.sg/product-thinking/), followed by an 8-question multiple-choice quiz.

## Contents

`index.html` — the whole thing. No build step, no dependencies, works offline.

**Summary** covers the three mindset shifts (solutions→problems, outputs→outcomes, big bang→staged delivery) and the toolkit from the seven linked guides:

| Guide | Concept |
| --- | --- |
| Understanding the Problem | Problems before solutions; Grab, Amazon, Netflix each nailed one problem first |
| Start With The Whys | Five Whys — symptom to root cause |
| Craft a Clear Problem Statement | The 4Cs: Clarity, Consequence, Cause, Confirmation |
| Metrics | SMART; leading vs lagging indicators; Value-Cost Ratio |
| Assumptions and Risks | Market/technical/team risk; PoC → PoV → Scale → Maturity |
| A Good Customer Experience | Compulsory services; the 11-Star Framework |
| Key Takeaways | Product thinking as a way of working |

**Quiz** — 8 MCQs, one per major concept. Answers unlock once all eight are selected; each is then marked with an explanation drawn from the source guide.

## Running it

Open `index.html` in any browser, or view the hosted version via GitHub Pages.

## Source

All content is summarised from the IDG Product Thinking pathway and its seven guides at [idg.gov.sg](https://www.idg.gov.sg/product-thinking/). Built as project 1 for Tinker Academy Agentic AI.
